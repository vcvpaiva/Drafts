## Drafts

Some drafts I'm working on at the moment (in no particular order; all need work) :

1. [Lineale-valued Sets](https://github.com/vcvpaiva/Drafts/blob/main/LinSet-2.pdf), draft extending [work](https://www.cs.man.ac.uk/~schalk/publ/pvsets.pdf) with Andrea Schalk, TCS 315, 2004.  Replacing the relations of Schalk and de Paiva's poset-valued sets by functions shows which linear structure comes from Rel and which remains over Set. Like sheaves, this extracts logic from the codomain, but needs far less. [blog post](https://logic-forall.blogspot.com/2026/09/what-is-actually-linear-here.html)
